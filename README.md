# 🍔 FoodFlow – UI/UX Design

A modern mobile food delivery application designed in **Figma** with a clean, intuitive, and user-friendly interface.

---

## 📖 Project Overview

FoodFlow is a mobile food delivery app UI/UX design created as part of my learning journey in UI/UX Design. The project focuses on creating a smooth ordering experience with an attractive interface and seamless navigation.

---

## ✨ Features

- 🚀 Splash Screen
- 🔐 Login Screen
- 🏠 Home Screen
- 🍕 Restaurant Listing
- 🍽️ Food Details
- 🛒 Shopping Cart
- 💳 Checkout
- ✅ Order Success Screen

---

## 🛠️ Tools Used

- Figma
- Interactive Prototyping
- Auto Layout
- Components
